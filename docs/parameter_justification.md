## A. φ (연령별 감수성) — 신규 확정 (문헌 기반 U자 고정)

### A.1 결정: φ=ones(15) 폐기 → 문헌 기반 U자 고정

현재 production 은 φ=ones(15). 진단 결과 이것이 연령 왜곡(0-5 과소예측
3배, 성인 과대)의 주원인. φ 는 비식별이므로 데이터 추정 불가 → γ_report·κ 와

### A.3 근거

**소아 배수 (2.0×):**
- 계절 인플루엔자 대표값으로 채택. 팬데믹(Cauchemez H1N1 1.96~3.2배)은 제외.
- 메타분석(Jayasundara): 소아:성인 attack rate ≈ 4.3배(15.2% vs 3.5%). 단 이는
  attack rate 로 접촉 효과 포함 → 접촉분(C_school)이 이미 모델에 있으므로 φ 에는
  순수 감수성만. household(접촉 통제) 연구의 2~3배가 순수 감수성에 근접.
- → 접촉분 제거 후 보수적 2.0× 채택. household 하한(Cauchemez US 1.96)과 정합.

**노인 (1.3~1.5×):**
- 계절 인플루엔자는 면역노화로 노인 감수성 높음(팬데믹 H1N1 은 반대라 제외).
- ⚠️ R0_IMMUNITY(65+=0.65)가 노인 사전면역을 이미 반영. R(0)=면역보유율,
  φ=감수성자의 접촉당 감염확률 → 다른 층이나 이중 억압 방지 위해 φ 는 보수적 1.5 상한.

**감수성만 반영, 감염성 제외:**
- 소아는 감수성↑이나 감염성은 성인과 유사(Vietnam HH cohort; Cauchemez).
- φ 는 susceptibility 항이므로 감수성 배수만. 감염성 차이는 넣지 않음.

**형태(U자) 정당화:**
- 접촉+사전면역만으로 연령별 위험 설명 불가, 별도 age-susceptibility 필요
  (Italy H1N1; Cauchemez 2014: 소아는 HI 항체 높아도 성인보다 감수성 높음).

## C. 파라미터 역할 분담 (이중 계산 방지 지도)
═══════════════════════════════════════════════════════════════

연령 효과가 여러 항에 분산되어 있어 이중 계산 위험. 각 항의 담당:

- **접촉 수·패턴** → C_channel (home/work/school/other). 데이터(NIMS).
- **연령별 감수성(접촉당 감염확률)** → φ. 문헌 고정(U자). [신규]
- **채널별 접촉당 전파율 배분** → π (logit_pi). field prior pin.
- **전체 전파 스케일** → R0. 데이터 추정.
- **사전면역(감염 안 되는 비율)** → R(0) profile. 문헌 고정.
- **관측 청구율** → γ_report. 문헌 고정.
- **감염기간/잠복** → γ/σ. 문헌 고정.

⚠️ 핵심 중복 주의:
- 노인: R(0)=0.65(면역보유) 와 φ=1.5(감수성) 는 다른 층 → 공존 OK, 단 φ 과도 금지.
- 소아: φ=2.0(감수성) 와 C_school(접촉 많음) 은 다른 층 → 공존 OK.
  attack rate 4배를 φ 에 다 넣으면 접촉과 이중계산 → φ 는 2.0 으로 보수적.
