## TODO-1: 백신을 S 뿐 아니라 R(0)에도 적용 (우선순위: 높음)

### 문제
현재 가정: 백신은 S(미면역)만 맞고 V로 이동. R(이미 면역)은 백신 안 맞음.

현실: 백신 맞는 사람은 자기 면역 상태 모름 → 이미 면역(R)인 사람도 맞음.
- 노인: R(0) 높음(0.65) + 접종률 가장 높음(82%)
- R에 있는 노인 상당수가 백신 맞는데 모델이 무시
- 접종 노력 상당 부분이 이미 면역인 사람에게 "낭비"되는데
  모델은 전부 S→V로 효과 낸다고 과대평가

### 왜 중요
- VE=0.5와 별개 문제. VE는 "맞은 사람 중 효과 비율",
  이건 "누가 맞느냐(S vs R)"의 문제.
- R(0)를 연령별 정교화(노인 0.65)했는데 백신은 S만 → 두 가정 불일치.
- 정책 시뮬레이션이 노인 백신 다루면 효과 과대평가 위험.

### 접근
- 백신을 S와 R 양쪽에 인구 비례 접종 (접종률 82%면 S의 82%, R의 82%)
- R 접종 → 효과 0 (이미 면역)
- S 접종 → VE 확률로 V 이동
- R로 간 접종분은 효과 없이 소진 → 현실적

### 검증
- 기존 S-only 대비 노인 결과 차이 (회귀)
- R(0) 높은 그룹에서 접종 효과 희석 확인

## TODO-2: post-pandemic 낮은 R(0) 시즌 검증 (우선순위: 중)

### 배경 (발표 피드백)
코로나 기간(2020-2022) 인플루엔자 거의 소멸 → 자연 감염 면역 거의 안 쌓임
→ 2022-23 시즌 시작 시 인구 면역(R(0))이 평년보다 낮았을 가능성.
현재 모든 시즌 동일 R(0) 계단 고정 → 2022-23엔 안 맞을 수 있음.

### 제안
유행 없던 시즌을 낮은 R(0)로 두고 2022-23 fitting 품질 확인.
2022-23이 우리 데이터의 post-pandemic 첫 시즌 → 이 시즌만 R(0) 낮춰
다른 시즌과 비교하면 깔끔한 검증. 잘 맞으면 R(0) 외부 근거 (문헌 보완).

### ★ 주의 (식별성 함정)
- R(0)도 β·φ·γ와 얽혀 비식별 위험
- R(0) "추정"하려 들면 ridge 재발
- → "추정" 아니라 "2022-23을 낮은 R(0) 시나리오로 고정 후 검증/forward"
- R(0)≈0은 비현실 (백신은 코로나 중에도 접종, 잔여 면역) → "낮음"이지 "0" 아님
