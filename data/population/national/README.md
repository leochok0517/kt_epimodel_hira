# National population — 상호성 보정 전용 (National)

접촉행렬 상호성 보정에 쓰는 인구벡터 $G$입니다. **전국 인구입니다.**

이 폴더는 상위 `data/population/`(수도권, 시즌별)과 **용도가 다릅니다.**
섞어 쓰지 마십시오.

| 폴더 | 대상 | 쓰이는 곳 |
|---|---|---|
| `data/population/` | 수도권(서울·인천·경기), 시즌별 | 모형의 FOI·초기상태 |
| `data/population/national/` ← 이 폴더 | **전국** | **접촉행렬 상호성 보정 한 곳** |

보정과 적용의 인구를 섞으면 결과가 무효가 됩니다. 이전 민감도 분석이
수도권 인구로 보정해서 폐기됐습니다.

---

## 어느 파일을 쓰는가

| 파일 | 기준 시점 | 15군 합계 | 용도 |
|---|---|---|---|
| **`pop_national_2024_01.csv`** | **2024.01** | **51,313,912** | **기본값. 이것을 쓰십시오** |
| `pop_national_2023_01.csv` | 2023.01 | 51,430,018 | 민감도용. 시점 선택의 영향 확인 |

### 왜 2024-01인가

접촉조사는 두 차례에 걸쳐 시행됐습니다.

```
1차   2023-12-06 ~ 12
2차   2024-02-07 ~ 13
```

**2024-01은 두 조사 기간 사이에 있습니다.** 두 시점을 평균하는 대신 그 사이의
공식 스냅숏을 쓰는 쪽이 단순하고 서술하기도 쉽습니다.

`pop_national_2023_01.csv`는 처음에 모형의 수도권 인구
(`kt_data/data/mapping/mois_population_202301.parquet`, 2023-01)와 시점을 맞추려고
넣었던 것입니다. 조사 시점과의 정합이 더 중요하다고 판단해 기본값을 2024-01로
바꿨고, 이 파일은 민감도 확인용으로 남겨 뒀습니다.

두 시점의 차이는 크지 않습니다. 총인구 -116,106명(-0.23%), 비중 차이가 가장 큰
구간이 70+와 65-69의 약 +0.5%p입니다. 보정 결과가 시점 선택에 민감하지 않음을
보이는 데 쓸 수 있습니다.

## 출처

- 행정안전부 주민등록인구, KOSIS 표
  `행정구역(동읍면)별 / 5세별 주민등록인구`
- 항목: **총인구수 (명)**
- 행정구역: **전국** (단일 행)
- 원본은 `raw/` 에 EUC-KR 그대로 보존

## 15군 매핑

원본은 5세 구간 21개(`0-4` … `95-99`, `100+`)입니다. 모형 규약에 맞춰
**70세 이상 7개 구간을 `70+` 하나로 합산**했습니다.

```
2024-01  70+ = (70-74)+(75-79)+(80-84)+(85-89)+(90-94)+(95-99)+(100+) = 6,343,437
2023-01  70+ = 6,106,089
```

## 전국과 수도권의 연령 구성 차이

전국 2024-01 대 수도권 2023-01(`mois_population_202301.parquet`, 합계 25,990,466).
**어느 인구로 보정하느냐가 시점 선택보다 훨씬 큰 차이를 만듭니다.**

| 0-4 | 2.58% | 2.83% | -0.24 |
| 5-9 | 3.87% | 4.04% | -0.17 |
| 10-14 | 4.54% | 4.52% | +0.02 |
| 15-19 | 4.52% | 4.52% | -0.00 |
| 20-24 | 5.42% | 5.89% | -0.47 |

| 35-39 | 6.17% | 6.96% | -0.79 |
| 40-44 | 7.87% | 8.21% | -0.34 |
| 45-49 | 7.54% | 8.00% | -0.46 |
| 50-54 | 8.77% | 8.87% | -0.09 |

70+ 비중이 2.15%p, 25-34 비중이 13.24% 대 14.85%로 갈립니다. 같은 전국 인구의
1년 차이(최대 0.5%p)보다 큽니다.

## 사용

```python
import csv, numpy as np
path = "data/population/national/pop_national_2024_01.csv"
rows = list(csv.DictReader(open(path)))
G = np.array([int(r["population"]) for r in sorted(rows, key=lambda r: int(r["band_index"]))])
assert G.shape == (15,), "15군이 아닙니다"
assert G.sum() == 51_313_912, f"전국 2024-01이 아닙니다 (합계 {G.sum():,})"
```

수도권 합계 25,990,466을 잘못 잡으면 두 번째 assert에서 걸립니다.
